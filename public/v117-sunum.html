🔐 Güvenli Logout

Oturum kapanınca token gerçekten geçersizleşiyor

Önce — Sahte Logout
Çıkış tıklandı
  ↓
localStorage silindi
← tek yapılan bu!

Refresh token hâlâ geçerli
Çalınan token → sisteme giriş ✓
→
Sonra — Gerçek Logout
Çıkış tıklandı
  ↓
POST /api/auth/logout
  ↓
user.tokenVersion → +1
  ↓
localStorage silindi

Eski token ile /refresh denenirse:
JWT.tv = 3 ≠ DB.tv = 4
→ 401 Yetkisiz ✗

🔍 Servis Filtresi — Alias Eşleşme

p.service === selectedId
"Acil Servis" === "svc-acil"
→ false → kişi görünmez! ✗

→

serviceMatching.js devreye girer:

{ "ACİL SERVİS", "ACIL", "svc-acil" }
