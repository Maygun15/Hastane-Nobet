Öne Çıkan Düzeltmeler

En kritik 6 düzeltme — before/after karşılaştırması ile.

🚨
alert() → toast() Migrasyonu
Tüm uygulama genelinde 91 adet tarayıcı native alert() çağrısı kaldırılarak Sonner toast bildirimleri ile değiştirildi. UX puanı dramatik biçimde arttı.
Önce (91 kullanım)
alert("Kayıt başarılı!");
alert("Hata: " + err.message);
if (!confirm("Silmek ister misiniz?")) return;
Sonra (0 kullanım)
toast.success("Kayıt başarılı!");
toast.error("Hata: " + err.message);
if (!window.confirm("Silmek ister misiniz?")) return;
📱
AuthCard Mobil Fix
Giriş kartı mobil ekranlarda sağdan taşıyordu. Sabit w-[420px] genişliği kaldırılıp w-full max-w-[420px] yapısına geçildi.
Önce
// src/ui/AuthCard.jsx — satır 91
<div className="w-[420px] bg-white ...">
Sonra
<div className="w-full max-w-[420px] bg-white ...">
♿
Focus Ring Erişilebilirlik
Tüm input ve select elementlerinde focus:outline-none yalnız başına bırakılmıştı. Klavye kullanıcıları için görsel odak göstergesi eklendi.
Önce
className="... focus:outline-none"
Sonra
className="... focus:outline-none
focus:ring-2 focus:ring-blue-400
focus:border-transparent"
🔒
Şifre Formu Label Erişilebilirliği
ChangePasswordModal içindeki 3 şifre input'unda id ve <label htmlFor> eksikti. Ekran okuyucular için form alanları tanımlandı.
Önce
<input type="password"
placeholder="Mevcut şifre" />
Sonra
<label htmlFor="current-password">
Mevcut Şifre
</label>
<input id="current-password"
type="password" ... />
🌐
document.title Dinamik Güncelleme
Sekme başlığı tüm oturum boyunca sabit "Hastane Nöbet Sistemi" kalıyordu. Her tab geçişinde sekme başlığı otomatik güncelleniyor.
Önce
// Sekme her zaman sabit gösteriyordu
<title>Hastane Nöbet Sistemi</title>
Sonra
useEffect(() => {
document.title =
`${labels[activeTab]} | Hastane Nöbet`;
}, [activeTab]);
🤖
FloatingAIChat Erişilebilirlik
Floating buton aria-label ve title attribute'larından yoksundu. Inline style'lar Tailwind className'lerine taşındı. Backdrop mobilde sm:hidden ile doğru gizlendi.
Önce
<button
title="AI Nöbet Asistanı"
style={{ position:'fixed', bottom:28,
right:28, zIndex:9999, ... }}>
Sonra
<button
aria-label={open ? "Kapat" : "AI Asistanı aç"}
title={open ? "Kapat" : "AI Asistan"}
className="fixed bottom-7 right-7
z-[9999] w-14 h-14 ...">
